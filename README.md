# Student Marks Management System (CLI)

I created this command-line interface (CLI) project during my diploma in CMJD in 2022. The system is implemented in Java using core object-oriented programming (OOP) concepts to manage student marks efficiently.

---

## Overview

This Java-based CLI application manages student records and their marks while demonstrating fundamental OOP principles such as encapsulation, inheritance, and polymorphism.

---

## Features

- Add new students with or without marks  
- Update student details and marks  
- Delete student records  
- Display student details and rankings based on marks  
- Identify top performers in specific subjects

---

## Purpose

This project serves as a practical implementation to strengthen OOP skills and improve understanding of data management and sorting algorithms in a real-world context. It is ideal for beginners learning Java or anyone interested in building simple CLI-based management systems.
